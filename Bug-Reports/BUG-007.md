# BUG-007 — Missing Response Action Buttons on Chrome Extension

## Bug ID
BUG-007

## Title
Missing Response Action Buttons on Chrome Extension

## Description
A difference was observed in the response action buttons available on the EchoGPT Android App and Chrome Extension when viewing AI-generated responses.

The Android App provides four response actions: **Copy, Like, Flag, and Retry**, while the Chrome Extension provides only **Copy and Retry**.

This was observed while testing the same account and AI model on both platforms.

## Steps to Reproduce

1. Sign in to the **EchoGPT Android App** using the test account.
2. Open the **Ask Anything** feature.
3. Send a message and wait for the AI response.
4. Observe the response action buttons displayed below the response.
5. Sign in to the **EchoGPT Chrome Extension** using the same account.
6. Open the **Ask Anything** feature.
7. Send a message and wait for the AI response.
8. Observe the response action buttons displayed below the response.
9. Compare the available response actions between the two platforms.

## Expected Result

Response action availability should match the defined product requirements for each supported platform. If **Like** and **Flag** are intended to be supported response actions, they should also be available on the Chrome Extension.

## Actual Result

The Android App displays **Copy, Like, Flag, and Retry**, while the Chrome Extension displays only **Copy and Retry**.

## Severity
Minor

## Priority
Medium

## Environment

- **Platform 1:** Android App
- **Platform 2:** Chrome Extension
- **Browser:** Google Chrome
- **AI Model:** EchoChat
- **Account:** Same test account used on both platforms
- **Date Tested:** 25 September 2026

| Platform | Available Actions |
|---|---|
| Android App | Copy, Like, Flag, Retry |
