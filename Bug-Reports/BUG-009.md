# BUG-009 — Compare Mode Models Remain Stuck on “Waiting for response...” in Chrome Extension

## Bug ID
BUG-009

## Title
Compare mode does not consistently return responses from selected models in the Chrome Extension

## Description
The **Compare** feature in the EchoGPT Chrome Extension does not consistently return responses from all selected AI models.

During testing, some selected models remained in the **“Waiting for response...”** state while other models completed successfully. When a higher number of models was selected, all selected models remained in the waiting state during testing.

The same Compare functionality was tested on the **Android App** using available/free models and worked normally.

## Steps to Reproduce
1. Open the **EchoGPT Chrome Extension**.
2. Open the **Compare** feature.
3. Select multiple available AI models.
4. Enter the prompt:
   `What is software testing?`
5. Submit the prompt.
6. Wait for the selected models to generate their responses.
7. Observe the response status for each selected model.
8. Repeat the test using different numbers of selected models.

## Expected Result
Each selected AI model should process the submitted prompt and return a response within a reasonable time.

If a model cannot process the request, the interface should provide a clear error or failure message instead of remaining indefinitely in a loading state.

## Actual Result
The Chrome Extension showed inconsistent response behavior:

| Models Selected | Chrome Extension Result |
|---:|---|
| 2 | Both models returned responses |
| 3 | 2 models returned responses; 1 model remained on **“Waiting for response...”** |
| 12 | All selected models remained on **“Waiting for response...”** during testing |
| 20 | All selected models remained on **“Waiting for response...”** during testing |

The Chrome Extension allows up to **20 models** to be selected and displays **“20/20 models selected”**, but the selected models did not return responses during the 20-model test.

The issue was **not observed on the Android App**, where Compare worked normally when tested with available/free models.
