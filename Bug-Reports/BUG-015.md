# BUG-015 — Paid Models Can Be Selected Without Immediate Restriction Warning

## Bug ID
BUG-015

## Title
Paid models can be selected without an immediate restriction warning

## Description
In **Image Studio**, models labeled as requiring a paid plan can still be selected by a user without an active paid subscription.

The application does not provide an immediate warning or prevent selection. The restriction is only communicated after the user enters a prompt and attempts to generate an image.

This results in the user spending additional steps preparing a prompt before discovering that the selected model cannot be used.

## Steps to Reproduce
1. Open the **EchoGPT Android App**.
2. Open **Image Studio**.
3. Open the image-generation model selector.
4. Select a model labeled **"Paid plan"**, such as **Nano Banana 2**.
5. Enter an image-generation prompt.
6. Observe the interface before generating.
7. Tap **Generate**.
8. Observe the result.

## Expected Result
When a user selects a paid-only model without an active paid plan, the application should either:
- prevent the user from selecting the model, or
- immediately display a clear message that the model requires a paid plan.

The user should be informed of the restriction before spending time composing a prompt.

## Actual Result
The paid model could be selected without any immediate warning.

After entering a prompt and tapping **Generate**, the application displayed:

**"Image generation is available on paid plans only. Upgrade to create images."**

The restriction was therefore communicated only after the generation attempt.

## Severity
Minor

## Priority
Medium

## Environment
- Platform: Android App
- Application: EchoChat
- Feature: Image Studio
- Model Tested: Nano Banana 2
