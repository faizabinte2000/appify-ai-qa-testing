# BUG-015 — Paid-Plan Requirement Is Not Clearly Disclosed Before Generation

## Bug ID
BUG-015

## Title
Paid-plan requirement is not clearly disclosed before image or video generation in the Chrome Extension

## Description
The EchoGPT Chrome Extension's Image Studio and Video Studio interfaces do not clearly disclose that generation is restricted to paid plans before the user attempts to generate content.

The Image Studio does provide the message **"Each image uses one message from your plan. Generation takes up to a minute."**, which communicates that generation uses the user's plan/quota. However, this does not explicitly indicate that image generation requires a paid plan.

Similarly, the Video Studio interface does not provide a clear pre-generation indication that video generation is restricted to paid plans.

The paid-plan restriction is only revealed after the user clicks **Generate**.

## Steps to Reproduce

### Image Studio
1. Open the EchoGPT Chrome Extension.
2. Open **Image Studio**.
3. Observe the information displayed before generation.
4. Enter a valid image-generation prompt.
5. Select an available image-generation model.
6. Click **Generate**.
7. Observe the message displayed.

### Video Studio
1. Open the EchoGPT Chrome Extension.
2. Open **Video Studio**.
3. Observe the information displayed before generation.
4. Enter a valid video-generation prompt.
5. Select an available video-generation model.
6. Click **Generate**.
7. Observe the message displayed.

## Expected Result
The Image Studio and Video Studio interfaces should clearly communicate the applicable paid-plan requirement before the user submits a generation request.

## Actual Result

### Image Studio
Before generation, the interface displayed:

**"Each image uses one message from your plan. Generation takes up to a minute."**

However, it did not explicitly indicate that image generation was available only on paid plans.

After clicking **Generate**, the application displayed:

**"Image generation is available on paid plans only."**

### Video Studio
Before generation, the interface did not explicitly indicate that video generation was available only on paid plans.

After clicking **Generate**, the application displayed:

**"Video generation is available on paid plans only."**
