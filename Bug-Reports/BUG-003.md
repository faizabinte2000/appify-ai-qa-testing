# BUG-003 — Create New Account Registration Blocked by Missing First Name Field

## Bug ID
BUG-003

## Title
Create New Account requires First Name although no First Name field is provided

## Description
The **Create New Account** flow in the Chrome Extension prevents the user from proceeding because it requires a First Name, but the registration form does not provide a First Name field.

## Steps to Reproduce

1. Open the **EchoGPT Chrome Extension**.
2. Open the authentication screen.
3. Select **Create New Account**.
4. Enter a valid email address.
5. Click **Send Verification Code**.
6. Observe the validation message.

## Expected Result

The registration form should provide all required fields, including First Name, or the system should not require a field that is not present in the form.

## Actual Result

The extension displays the message **"First name is required"**, but there is no First Name field available on the Create New Account screen.

The user therefore cannot provide the required information and cannot proceed with registration.

## Severity
Major

## Priority
High

## Environment

- Platform: Chrome Extension
- Browser: Google Chrome
- Date Tested: 23 September 2026
