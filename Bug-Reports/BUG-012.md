# BUG-012 — Screenshot Attachment Fails Due to Unsupported PNG Format

## Bug ID
BUG-012

## Title
Screenshot attachment fails because the generated PNG format is reported as unsupported

## Description
The Chrome Extension provides a **Screenshot/Scissors** feature that captures a screenshot and attaches it to the chat as a PNG file.

However, when the screenshot is submitted for AI processing, the application reports that the `image/png` file type is unsupported.

The screenshot is successfully attached to the chat input, but the application fails to process the attachment.

## Steps to Reproduce
1. Open the EchoGPT Chrome Extension.
2. Navigate to the chat screen.
3. Click the **Screenshot/Scissors** icon.
4. Capture a screenshot.
5. Verify that `screenshot.png` is attached to the message input.
6. Enter a message requesting analysis of the screenshot.
7. Send the message.
8. Observe the result.

## Expected Result
The screenshot captured using the Screenshot/Scissors feature should be successfully processed and made available to the AI for analysis.

## Actual Result
The screenshot is attached as `screenshot.png`, but processing fails with the following message:

**"File processing failed: Unsupported file type: image/png. Supported types: PDF, DOCX, XLSX, XLS, TXT."**

The AI cannot process the attached screenshot.

## Severity
Major

## Priority
High

## Environment
- Platform: Chrome Extension
- Browser: Google Chrome
- AI Model: EchoChat
- File Type: PNG (`image/png`)
- Date Tested: 26 September 2026
