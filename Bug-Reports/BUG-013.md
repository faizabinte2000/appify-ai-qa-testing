# BUG-013 — Connected Google Drive MCP Tool Cannot Be Used in Chat

## Bug ID
BUG-013

## Title
Connected Google Drive MCP tools are not invoked from chat

## Description
The Google Drive MCP server can be successfully connected through the EchoGPT MCP Connectors section, and `get_file_metadata` is displayed among the available Google Drive tools. However, the chat does not recognize or invoke the connected MCP tool when explicitly requested.

## Steps to Reproduce
1. Open the EchoGPT Chrome Extension.
2. Open **MCP Connectors**.
3. Connect the Google Drive MCP server:
   `https://drivemcp.googleapis.com/mcp/v1`
4. Verify that Google Drive is displayed as **Connected**.
5. Verify that `get_file_metadata` is listed among the available Google Drive tools.
6. Open a new chat.
7. Enter the following prompt:

   `Use the connected Google Drive connector and call the get_file_metadata tool for this file. File ID: 1HMaVqFvz2arzXDms4lNR0-B_DAIcOg-p. Return the file name, MIME type, file size, created time, and last modified time.`

8. Submit the prompt.
9. Observe whether the MCP tool is invoked.

## Expected Result
EchoGPT should recognize the connected Google Drive MCP server and invoke the `get_file_metadata` tool using the provided file ID.

The metadata for the requested file should be returned in the chat.

## Actual Result
EchoGPT stated:

> "I don't have access to a Google Drive connector or the `get_file_metadata` tool in this environment..."

It did not invoke the connected Google Drive MCP tool.

Instead, it provided instructions for manually accessing the Google Drive API.
