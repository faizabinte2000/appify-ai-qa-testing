# BUG-016 — Stale Session Causes Internal Error After Account Deletion

## Bug ID
BUG-016

## Title
Chrome Extension displays an internal error when using a session for an account deleted from another platform

## Description
When an EchoGPT account is deleted from the Android App while the same account remains signed in to the Chrome Extension, the Chrome Extension does not invalidate the existing session.

The extension continues to display the account as signed in. However, when the user attempts to perform an action such as text generation, the application displays an internal JavaScript error instead of safely handling the invalid session or informing the user that the account is no longer available.

## Steps to Reproduce

1. Sign in to the same EchoGPT account on the Android App and Chrome Extension.
2. Delete the account from the Android App.
3. Leave the Chrome Extension open or do not manually sign out from it.
4. Open the EchoGPT Chrome Extension.
5. Verify that the deleted account is still displayed as signed in.
6. Attempt to send a text-generation prompt.
7. Observe the result.

## Expected Result

The Chrome Extension should detect that the account has been deleted and invalidate the stale session.

The user should be redirected to the authentication screen or shown a clear user-facing message explaining that the account is no longer available.

The application should not expose an internal error.

## Actual Result

The Chrome Extension continued to display the deleted account as signed in.

When a text-generation action was attempted, the application displayed:

**"Sorry, I encountered an error: Cannot read properties of null (reading 'quotaWindowStart')"**

The expected quota/usage handling was not displayed, and the user could not continue normally.

## Severity

Major

## Priority

High

## Environment

- Platform: Chrome Extension
- Browser: Google Chrome
- Secondary Platform: Android App
- Scenario: Account deleted from Android while session remained active in Chrome Extension
- Feature: Text Generation / Account Session
- Date Tested: 27 September 2026

## Notes

The Chrome Extension retained the authenticated session after the account was deleted from the Android App.

The error references `quotaWindowStart`, indicating that the application attempted to access quota-related data that was unavailable for the deleted account.
