# BUG-014 — Paid Plan Label Appears Only After Failed Image Generation Attempt

## Bug ID
BUG-014

## Title
"Paid plan" label is only displayed after a failed image generation attempt

## Description
The Image Studio model selector does not initially indicate which image-generation models require a paid plan.

When a user selects a model and attempts to generate an image without a paid subscription, the generation fails with a paid-plan restriction. After the failed attempt, the selected model is then labeled **"Paid plan"** in the model selector.

This means the access restriction is revealed only after the user has already attempted to use the model.

## Steps to Reproduce
1. Open the **EchoGPT Android App**.
2. Open **Image Studio**.
3. Open the image-generation model selector.
4. Observe the available models before attempting generation.
5. Select an image-generation model.
6. Enter an image-generation prompt.
7. Tap **Generate**.
8. Observe the paid-plan restriction message.
9. Return to the model selector.
10. Observe the label displayed for the previously selected model.
11. Repeat the test with another image-generation model.

## Expected Result
Models that require a paid plan should clearly display their **"Paid plan"** status before the user attempts to generate an image.

The user should not need to attempt generation and encounter a failure before learning that the selected model requires a paid subscription.

## Actual Result
Initially, none of the image-generation models displayed a **"Paid plan"** label.

After attempting to generate an image and receiving the paid-plan restriction message, the model subsequently displayed a **"Paid plan"** label.

The same behavior was observed with other models: the label appeared only after an unsuccessful generation attempt using that model.
