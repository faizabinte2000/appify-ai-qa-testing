# BUG-014 — Inconsistent "Paid Plan" Labeling Across Image Studio Models

## Bug ID
BUG-014

## Title
Inconsistent "Paid plan" labeling across Image Studio models

## Description
The **Image Studio** model selector does not consistently indicate whether image-generation models require a paid plan.

Some models display a **"Paid plan"** label, while other models do not display any access-tier information. This makes it unclear which models are available to the current user and which require a paid subscription.

## Steps to Reproduce
1. Open the **EchoGPT Android App**.
2. Open **Image Studio**.
3. Open the image-generation model selector.
4. Review all available image-generation models.
5. Compare the access labels displayed for each model.

## Expected Result
Every image-generation model should consistently display its access tier, such as **Free** or **Paid plan**, so users can clearly understand whether a model requires a paid subscription.

## Actual Result
Access-tier labeling is inconsistent.

The following models displayed a **"Paid plan"** label:
- Nano Banana 2 Lite
- Nano Banana 2

The following models did not display an access-tier label:
- Nano Banana Pro
- Nano Banana
- ChatGPT Image Latest
- GPT Image 1

This makes the availability and subscription requirements of the unlabeled models unclear.
