# BUG-014 — Paid Plan Label Appears Only After Failed Generation Attempt

## Bug ID
BUG-014

## Title
"Paid plan" label is displayed only after a failed image generation attempt

## Description
The Image Studio model selector does not initially indicate that image-generation models require a paid plan.

A user can select a model and attempt to generate an image without seeing any paid-plan indication. After the generation attempt is rejected because the account does not have a paid plan, the selected model is then labeled "Paid plan".

This results in the access restriction becoming visible only after the user has already attempted to use the feature.

## Steps to Reproduce
1. Open the EchoGPT Android App.
2. Open Image Studio.
3. Open the image-generation model selector.
4. Observe the available models before attempting generation.
5. Select an image-generation model.
6. Enter an image-generation prompt.
7. Tap Generate.
8. Observe the paid-plan restriction message.
9. Return to the model selector.
10. Observe the label displayed for the previously selected model.
11. Repeat the test with another image-generation model.

## Expected Result
The model selector should provide clear and consistent information about model access requirements.

A model's paid-plan requirement should not become visible only after the user has attempted generation and encountered a restriction.

## Actual Result
Initially, none of the image-generation models displayed a "Paid plan" label.

After attempting to generate an image and receiving the paid-plan restriction message, the selected model subsequently displayed a "Paid plan" label.

The same behavior was observed with other models: the label appeared only after an unsuccessful generation attempt using that model.
