# BUG-005 — Email Autocomplete Suggestions Cannot Be Selected

## Bug ID
BUG-005

## Title
Email autocomplete suggestions cannot be selected in the Chrome Extension

## Description
When entering an email address in the EchoGPT Chrome Extension's email authentication field, email suggestions appear while typing. However, the displayed suggestions cannot be selected using either mouse interaction or keyboard navigation.

The behavior was reproduced using two different Google accounts.

## Steps to Reproduce

1. Open the **EchoGPT Chrome Extension**.
2. Open the **Sign In with Email** screen.
3. Click inside the email input field.
4. Start typing an email address that has previously been used in the browser.
5. Wait for an email suggestion to appear.
6. Try selecting the suggested email using a mouse click.
7. Try selecting the suggestion using the keyboard **↓** key followed by **Enter**.
8. Repeat the test using another Google account.

## Expected Result

When an email suggestion is displayed and selected by the user, the suggested email address should be entered into the email field.

## Actual Result

The email suggestions appear while typing, but selecting them using either:

- Mouse click
- Keyboard **↓ + Enter**

does not populate the email field.

The user must manually type the complete email address.

The same behavior was reproduced using two different Google accounts.
