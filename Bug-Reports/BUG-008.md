# BUG-008 — No Persistent Quota Indicator in Chrome Extension

## Bug ID
BUG-008

## Title
Chrome Extension does not display the remaining message quota before the usage limit is reached

## Description
The EchoGPT Android App displays the user's remaining message quota and reset information during normal usage. However, the Chrome Extension does not display the remaining quota before the usage limit is reached.

The Chrome Extension only displays the usage-limit information after the user reaches the limit, within an error-style message.

## Steps to Reproduce

1. Open the EchoGPT Android App and sign in.
2. Observe the message usage indicator during normal usage.
3. Note the displayed remaining message count and reset information.
4. Open the EchoGPT Chrome Extension using the same account.
5. Use the chat normally without reaching the message limit.
6. Observe the interface for any visible message quota or remaining-message indicator.
7. Continue sending messages until the usage limit is reached.
8. Observe how the Chrome Extension communicates that the limit has been reached.

## Expected Result

The Chrome Extension should provide a visible indication of the user's remaining message quota and, where applicable, the reset time before the usage limit is reached.

When the limit is reached, the application should clearly communicate that the user's quota has been exhausted and provide relevant reset information.

## Actual Result

The Chrome Extension does not display a persistent message quota indicator during normal usage.

The remaining quota is not shown until the usage limit is reached, at which point the limit information appears within an error-style message.

The Android App proactively displays the remaining message count and reset information during normal usage.

## Severity
Major

## Priority
High

## Environment

- Platform 1: Chrome Extension
- Platform 2: Android App
- Browser: Google Chrome
- AI Model: EchoChat
- Account: Same test account used on both platforms
- Date Tested: 25 September 2026

## Platform Comparison

| Platform | Result |
|---|---|
| Android App | **Pass — remaining quota and reset information visible during normal usage** |
| Chrome Extension | **Fail — no quota indicator until usage limit is reached** |
