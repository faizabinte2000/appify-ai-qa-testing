# BUG-004 — Chrome Extension Sign Out Does Not Persist

## Bug ID
BUG-004

## Title
User is automatically signed in again after signing out and reopening the Chrome Extension

## Description
The **Sign Out** function appears to work initially, but the signed-out state is not maintained after the Chrome Extension is closed and reopened. The user is automatically authenticated again without performing a new sign-in.

## Steps to Reproduce

1. Open the **EchoGPT Chrome Extension** while already signed in.
2. Open the account/profile menu.
3. Click **Sign Out**.
4. Confirm that the authentication screen is displayed.
5. Close the Chrome Extension/sidebar.
6. Reopen the EchoGPT Chrome Extension.
7. Observe the authentication state.

## Expected Result

After signing out, the user's authenticated session should be terminated.

When the extension is reopened, the user should remain signed out and be required to authenticate again.

## Actual Result

After clicking **Sign Out**, the user is initially returned to the authentication screen.

However, after closing and reopening the Chrome Extension, the user is automatically signed in again without entering credentials or completing authentication.

## Severity
Major

## Priority
High

## Environment

- Platform: Chrome Extension
- Browser: Google Chrome
- Date Tested: 25 September 2026
